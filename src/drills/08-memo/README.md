# memo, useMemo, useCallback

| Варіант                                               | Скільки разів ререндерилася TaskRow | Найдовший commit (ms)            |
| ----------------------------------------------------- | ----------------------------------- | -------------------------------- |
| (а) без мемоїзації                                    | 5000 на кожен символ в пошуку       | ± 200ms на кожен символ в пошуку |
| (б) memo + `task={{ ...t, done: doneIds.has(t.id) }}` | 5000 на кожен символ в пошуку       | ± 200ms на кожен символ в пошуку |
| (в) примітивні props                                  | 0                                   | 0                                |

У (а) майже кожен ререндер батька тягне всі відфільтровані рядки; у (б) `React.memo` майже не допомагає, бо новий об’єкт `task` щоразу ламає shallow compare; у (в) оновлюється лише те, що реально змінилось (набір у пошуку або один чекбокс).
